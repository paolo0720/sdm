# Part 03 – OOP

This lecture introduces the core concepts of Object-Oriented Programming (OOP) and contrasts it with other major programming paradigms. It uses conceptual examples to explain why OOP is a powerful way to model complex systems.

## Content
- **Programming Paradigms**:
    - **Imperative**: Procedural and Object-oriented.
    - **Declarative**: Functional and Logic.
- **Procedural vs. Object-Oriented**:
    - Procedural: Programs as a sequence of procedures operating on data; early binding/static dispatch.
    - OOP: Programs as a community of interacting objects; late binding/dynamic dispatch.
- **Core OOP Concepts**:
    - **Objects**: Reusable units defining both state (variables) and behavior (methods).
    - **Abstraction**: Hiding details to show only essential information, often context-dependent.
    - **Responsibility**: Defining what an object does within its community.
    - **Encapsulation**: Separation of interface from implementation and data protection (the "black box" concept).
    - **Inheritance**: Primarily for code reuse, enabling a child class to inherit behavior and data from a parent.
    - **Polymorphism**: The ability for objects of different classes to be treated as objects of a common superclass ("many forms").
- **Additional Topics**: 
    - Introduction to interfaces for cross-hierarchy polymorphism.
    - **Duck Typing**: Conceptual overview using Python as an example ("If it walks like a duck...").

## Learning Objectives
By the end of this part, students are expected to:
- Distinguish between different programming paradigms.
- Explain the shift from procedural to object-oriented thinking.
- Define and provide examples of abstraction, encapsulation, inheritance, and polymorphism.
- Understand the role of objects as providers of services within a system.
