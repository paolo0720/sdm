# Part 01 – Hello, World!

This lecture introduces the Java programming language through the classic "Hello, World!" example, updated to reflect the latest features in Java 25. It also provides the necessary background to get started with the Java ecosystem.

## Content
- **«Hello, World!» explained**: Understanding the simplest Java program using modern syntax (top-level `main` method and the `IO` class).
- **Compilation and Execution**: Using `javac` to turn source files into `.class` bytecode files and `java` to run them on the Java Virtual Machine (JVM).
- **Java 25 vs. Earlier Versions**: A comparison between the modern simplified syntax and the traditional `public static void main(String[] args)` boilerplate.
- **The Java Platform**: How bytecode makes Java independent of hardware and operating systems ("Write once, run anywhere").
- **Language Comparison**: Brief comparison of syntax and execution models with Python and C++.
- **Characteristics of Java**:
    - Object-oriented (Inheritance, encapsulation, polymorphism).
    - Statically typed.
    - Automatic garbage collection.
    - Multi-threaded and robust error handling.
- **Getting Started**: 
    - JRE vs. JDK distributions.
    - Choosing a version (LTS vs. short-term) and vendor (Oracle, Adoptium, etc.).
    - Navigating official documentation and the Java Community Process (JCP).

## Learning Objectives
By the end of this part, students are expected to:
- Write, compile, and run a simple Java program using both traditional and modern syntax.
- Understand the role of the JVM and bytecode in achieving platform independence.
- Identify the core technical characteristics of the Java language.
- Set up their development environment and know where to find official API documentation.
